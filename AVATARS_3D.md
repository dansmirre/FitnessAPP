# Мужской и женский 3D-персонажи FORMA

В версии 2.3 уже есть настоящие базовые 3D-персонажи: геометрия генерируется локально, поворачивается пальцем или кнопкой. Мужская и женская фигуры имеют разные пропорции, одежду и причёску; пять этапов меняют пропорции. Это простые стилизованные модели, по детализации они отличаются от персонажей на референсах. Миниатюры этапов пока остаются векторными.

Чтобы получить качество как на скриншотах, нужен художник или собственная работа в Blender. Фотографии дают визуальный ориентир, но не содержат готовую вращающуюся модель.

## Как создать модели

1. **Сделать две базовые фигуры.** В Blender создать мужскую и женскую фигуры или взять базовую сетку из MakeHuman/другого генератора с подходящими условиями использования. Для стилистики референса увеличить голову и глаза, смягчить анатомические формы и сделать естественные пропорции. Фигура должна смотреть вперёд вдоль +Z, вверх — +Y после glTF-экспорта.
2. **Добавить внешний вид.** Мужчине — чёрные шорты и кроссовки; женщине — спортивный топ, шорты и кроссовки. Отдельно смоделировать волосы, лицо, уши и кисти. Проверить силуэт спереди, сбоку и сзади. Настроить PBR-материалы кожи, ткани, волос и обуви.
3. **Сделать пять вариантов телосложения.** В Blender использовать Shape Keys с одной топологией: `BodyThin`, `BodySlim`, `BodyFit`, `BodyAthletic`, `BodyPowerful`. Каждый ключ должен представлять целиком нужную форму относительно Basis: при показе выбранный ключ = 1, остальные = 0. На сетках одежды должны быть одноимённые ключи, чтобы одежда следовала за телом и не пересекала его. Имена должны сохраниться как glTF morph target names.
4. **При необходимости добавить анимацию.** Сделать скелет и короткую зацикленную анимацию дыхания с именем `Idle`. Без анимации модель тоже работает. При системной настройке уменьшения движения Idle не запускается.
5. **Оптимизировать.** Ориентир для телефона: 20–50 тысяч треугольников на персонажа, текстуры 1024×1024, файл по возможности 2–5 МБ. Это бюджет, а не обязательный предел. Проверить на реальном телефоне в Telegram, особенно iOS. В текущем просмотрщике не настроены Draco/KTX2-декодеры: экспортировать обычный GLB без таких расширений.
6. **Экспортировать из Blender.** Формат glTF 2.0 → GLB. Включить Shape Keys и, если есть, анимации. Все текстуры и буферы встроить в один GLB; внешние URL не использовать. Применить трансформации объекта, проверить, что Shape Keys и одежда экспортировались корректно.
7. **Подключить.** Положить файлы в `assets/avatars/male.glb` и `assets/avatars/female.glb`. Перезапустить/обновить сайт и страницу. Имена файлов фиксированы; сервер уже разрешает их выдачу. Код автоматически нормализует высоту модели, ставит её на пол и выбирает Shape Key текущего этапа. Модель с отсутствующими Shape Keys будет вращаться, но менять телосложение не сможет.

## Что уже подключено в коде

- `character3d.js`: локальные модели, Three.js, WebGL, свет, вращение, загрузчик GLB и Shape Keys.
- `avatar3d.bundle.js`: готовая локальная сборка; CDN не нужен. Если модель успешно загружена при работающем Service Worker, GLB кэшируется для офлайна.
- Уровни и этапы определяет `bodyProgress` в `profile-model.js`: от выбранного стартового этапа добавляется один этап на уровнях 6, 11, 16, 21, максимум пять этапов.
- WebGL недоступен → остаётся векторная иллюстрация с видами спереди и сзади.
- Вращение — горизонтальный жест, нажатие на фигуру либо кнопку под ней. Вертикальный жест сохраняет прокрутку страницы.
- При смене раздела геометрия, материалы, текстуры и контекст предыдущей сцены освобождаются. Базовая неподвижная модель не перерисовывается непрерывно.

После изменения `character3d.js` выполнить:

```bash
npm ci
npm run build:avatar
npm test
```

Для запуска уже собранного приложения достаточно Node.js 20+ и `npm start`: готовая сборка хранится в репозитории. При изменении библиотеки проверьте `THIRD_PARTY_LICENSES.txt`.

## Проверка моделей перед публикацией

Проверить оба пола, все пять этапов, вид со всех сторон, отсутствие пересечений одежды, анимацию, фон и освещение; затем работу офлайн и на устройствах без WebGL. Размер и скорость загрузки нужно измерить на настоящем телефоне. Реалистичный вид модели зависит от качества геометрии, текстур и материалов; настройка просмотрщика сама по себе не создаёт художественную модель уровня референса.
