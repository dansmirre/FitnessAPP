В этом каталоге можно разместить `male.glb` и `female.glb`.

Приложение автоматически заменит базового процедурного персонажа подходящей GLB-моделью. Если файла нет или он не загружается, останется встроенный 3D-персонаж; если недоступен WebGL — 2D-иллюстрация.

Техническое задание на модели: [../../AVATARS_3D.md](../../AVATARS_3D.md).
