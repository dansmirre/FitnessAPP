# FORMA · FitnessAPP

Фитнес Mini App для Telegram и браузера. Четыре раздела: главная с аватаром, упражнения, прогресс и профиль.

## Быстрый запуск

Нужен Node.js 20+. Внешних npm-зависимостей нет.

```bash
npm start
```

Откройте http://localhost:3000 в браузере на том же компьютере. Другой порт: `PORT=8080 npm start`. Проверки: `npm test`.

## Как проверить

1. Измените имя, параметры тела и XP за тренировку в «Профиле».
2. Добавьте упражнение: группу мышц, описание, подходы, повторения, рабочий вес, HTTPS-ссылку на фото или видео.
3. Нажмите «Начать тренировку», укажите фактические результаты и отметьте выполненные упражнения.
4. Завершите тренировку: в «Прогрессе» появятся история, объём нагрузки и XP (по умолчанию +10). Пустая тренировка XP не даёт.
5. Перезагрузите страницу: записи сохранятся. Для переноса данных используйте экспорт/импорт JSON в профиле.

Прямые ссылки на PNG/JPEG/WebP/GIF показывают фото, MP4/WebM — видео. Остальные медиа-ссылки открываются отдельно.

## Telegram и публикация

Разместите статические файлы приложения на публичном HTTPS-хостинге и задайте адрес Mini App / кнопки меню через BotFather. Можно использовать GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). После публикации укажите выданный GitHub адрес в BotFather. Включение Pages и публикация в Telegram не выполняются автоматически при загрузке кода.

Клиент вызывает Telegram WebApp ready/expand и работает также вне Telegram. Не помещайте токен бота в клиентский код. Проверка Telegram initData на сервере потребуется при добавлении backend.

## Офлайн и ограничения

Service Worker кэширует интерфейс после первого успешного открытия на HTTPS или localhost. На поддерживаемом браузере после этого можно записывать тренировки без сети. В Telegram WebView доступность Service Worker зависит от клиента; отдельную версию можно установить из браузера на домашний экран. Внешние фото, видео и Telegram SDK требуют сети.

Данные хранятся в localStorage конкретного браузера. Нет backend, регистрации и синхронизации между устройствами. Очистка данных браузера удалит записи — сохраняйте резервные копии. Аватар является условной иллюстрацией с ручной настройкой ширины, а не измерением реальных изменений тела.
